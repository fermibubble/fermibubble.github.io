A small working glossary

Harness
The execution loop, tools, state, policies, and feedback surrounding a model. Read more
Progressive disclosure
Reveal an interface or evidence when it becomes relevant, while keeping the route to it discoverable. Read more
Checkpoint replay
Resume a recorded decision with only the information available at that checkpoint. Read more
Provenance
The source, transformations, scope, and time that make an evidence claim inspectable. Read more
Ground truth
A versioned reference judgment under a defined policy, including disagreement and unresolved cases. Read more
Calibration
Whether stated probabilities match observed frequencies over comparable cases. Read more
Selective risk
The error rate among accepted decisions as uncertain cases are deferred. Read more
Authority gate
A separate release or runtime condition for permitted actions; correctness cannot compensate for violating it. Read more
Compare and swap (CAS)
Apply a write only if the stored version still matches the version the worker read. Read more
Paired evaluation
Compare candidates on the same tasks and account for which tasks changed outcome. Read more
Counterfactual
What would have happened under a different action; a fixed recording alone cannot establish it. Read more
Negative caching
Cache an absence or failure under an explicit validity policy; stable absence differs from a transient outage. Read more
