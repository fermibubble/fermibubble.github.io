Classical hill climbing keeps a candidate when a nearby change improves the objective. For an agent, a “nearby” change might be one prompt edit. The landscape can contain plateaus, noisy slopes, and local peaks. Sometimes the next useful move is a different tool or workflow, which changes the available search space.

Atlas could spend hundreds of iterations polishing “be thorough.” If certificate information never enters its context, that search has a structural limit. Adding a reliable inspection tool changes what the system can know. The right intervention may therefore lie outside the component currently being optimized.

Language models add a powerful search mechanism: execution feedback can be interpreted as a proposal for a change. Instead of learning only that a score was low, an optimizer can inspect the tool output that was missed and propose how to use it.

DSPy made modular language-model programs and their optimization an explicit programming approach. TextGrad propagates natural-language critiques through a computation graph to update components. Its “gradients” are textual feedback rather than exact mathematical derivatives, so candidate changes still require evaluation. [13] [14]

GEPA uses reflection on execution traces to propose prompt updates and preserves complementary candidates along a Pareto frontier. Keeping several useful candidates can retain discoveries that a greedy sequence would discard. Its February 2026 revision reports an average 6% advantage over GRPO across six tasks, using up to 35 times fewer rollouts; those are the authors' task- and budget-specific comparisons, not a general claim that prompt search replaces reinforcement learning. [15]

ACE moves attention toward the context that persists between attempts. It separates generation, reflection, and curation, updating an evolving playbook. Its context-collapse case study shows why indiscriminate rewriting can erase useful detail: the memory can get shorter while the system gets worse. The broader lesson is to test additions and preserve useful structure, rather than assume that every reflection deserves to become a permanent rule. [16]

This is a map of mechanisms, not a universal leaderboard. Their tasks, budgets, models, and feedback differ. For Atlas, the choice follows the suspected bottleneck: missing evidence calls for a different change from poor instructions or forgotten knowledge.

THE POWERFUL IDEA

Use feedback to search intelligently, and use independent evidence to decide what to keep.
