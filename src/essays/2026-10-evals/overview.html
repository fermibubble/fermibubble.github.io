A correct diagnosis can still produce an unsafe recommendation. This guide uses an illustrative checkout incident to separate those judgments, turn them into a scoring contract, and decide what a release result actually supports.

Three parts contain nine chapters. Each part can be read on its own:

  • Design the Test: define the task, evidence, valid alternatives, and rubric.
  • Build the Score: inspect correctness, completion, authority, and the interactive scoring example.
  • Trust the Result: calibrate judgments, account for repeated runs, and assess a release.

Download the Python scoring companion and the paired-comparison workbench. The supplied judgments and datasets are illustrative. They are not measured model results.
